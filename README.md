# 浮方工具箱 (FuFangTools)

浮方工具箱是一个小巧、美观的在线工具集合，旨在提供便捷的日常开发与生活辅助功能。支持在线访问，同时也支持打包为离线桌面应用。

## 🛠️ 功能列表

目前包含以下实用工具：

*   **24点计算器**: 输入4个数字，自动寻找所有可能的24点解法，内置多种算法。
*   **短链接转换器**: 支持批量输入，一键还原多个短链接背后的原始长地址（需要网络）。
*   **BMI计算器**: 输入身高和体重，快速计算身体质量指数（BMI）及健康建议。
*   **二维码生成工具**: 输入任意文本或网址，即时生成可自定义的二维码图片。
*   **Base64 转换**: 强大的 Base64 编码与解码工具，支持中文字符，界面简洁。
*   **网页内容预览**: 支持推特 (X)、YouTube、Bilibili 等社交媒体链接的嵌入式预览，**支持国内免翻墙代理预览**。
*   **趣味题解与图示**: 针对经典数学真题（如2022年高考乙卷理科数学第11题）打造的交互式动态几何实验室，支持 Retina 高清绘制、移动端旋转横屏全屏探索与 MathJax 矢量公式排版。

## 🚀 使用指南

### 1. 在线使用
您可以直接访问我们的在线版本使用所有功能（无需安装）。

### 2. 桌面版离线使用
如果您需要即使断网也能使用（除短链接还原外的）所有工具，可以将本项目打包为 Windows 桌面应用。

*   **打包指南**: 详见 [PKG_BUILD.md](./docs/PKG_BUILD.md)

### 3. 服务器部署
如果您拥有自己的服务器，想部署一份私有的工具箱：

*   **阿里云/服务器部署指南**: 详见 [DEPLOY_ALIYUN.md](./docs/DEPLOY_ALIYUN.md)

## 💻 本地开发

如果您是开发者，想要贡献代码或修改功能：

1.  **安装依赖**:
    ```bash
    npm install
    ```
2.  **启动本地开发环境 (Vite 客户端 + Express API)**:
    您可以开启两个终端分别运行前端和后端：
    ```bash
    # 终端 1：启动 Express 后端 API (用于短链接等接口)
    npm start

    # 终端 2：启动 Vite 前端热更新服务
    npm run dev
    ```
    启动后访问 Vite 提供的本地地址（通常是 `http://localhost:5173`）。

3.  **构建生产版本**:
    ```bash
    npm run build
    ```
