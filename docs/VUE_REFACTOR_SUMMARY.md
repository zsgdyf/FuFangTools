# 浮方工具箱 (FuFangTools) - Vue 3 重构总结

## 🎯 重构目标
将原有的原生 HTML + JS + CSS 多页面应用，平滑重构为基于 **Vue 3 (Composition API) + Vite** 的单页面应用 (SPA)。在保持原有 UI 视觉效果和所有功能逻辑**完全不变**的前提下，实现代码的组件化、模块化，从而大幅提升后期的可维护性和扩展性。

---

## 🏗️ 架构与技术改进

### 1. 现代化构建工具 (Vite + Vue 3)
*   移除了传统的 CDN 脚本引入方式，改用 `npm` 管理依赖（如 `qrcode-generator`）。
*   采用 Vite 提供了极速的本地热更新 (HMR) 体验和高效的生产环境构建。
*   各个工具页面被拆分为独立的 `.vue` 单文件组件，实现了视图、逻辑、样式的内聚。

### 2. 路由系统重构 (Vue Router)
*   全面采用 **Hash 模式路由** (`/#/calc-24`)，完美兼容了 Cloudflare Pages 的静态托管限制以及阿里云的 Nginx 部署。
*   实现了**路由懒加载**，首页仅加载核心骨架，进入具体工具（如二维码生成、Base64 转换等）时才动态请求对应的资源代码，优化了首屏加载速度。

### 3. 组件化与复用
*   **`ToolLayout.vue`**: 抽象了所有工具页面的通用布局（返回按钮、标题栏、最大宽度限制），避免了代码重复。
*   **`IcpFooter.vue`**: 将原生 JS 中的 DOM 拼接逻辑改写为声明式的 Vue 组件。通过读取 `/api/app-config`，实现了**动态备案信息展示**（阿里云显示备案号，Cloudflare 隐藏）。

### 4. 算法与业务逻辑解耦
*   将 **24点计算器算法** 和 **Base64 编解码** 等纯业务逻辑，从 UI 操作中完全剥离，放置到了 `src/utils/` 目录下（如 `calc24Solver.js`）。这使得算法变成了纯函数，不仅方便了 Vue 状态调取，还为未来的单元测试打下了基础。

### 5. 样式冲突彻底解决
*   解决了原有原生 CSS 全局污染的痛点。将全局样式抽象到 `theme.css`，工具界面的特定样式严格使用 `<style scoped>` 进行隔离。
*   利用 Vue 的 `:deep()` 穿透选择器，优雅地将统一样式下发给插槽 (`<slot>`) 中的子元素，在“样式隔离”与“UI 一致性”之间取得了完美平衡。

---

## 🚀 部署架构的完美适配
本次重构完全兼容了用户特殊的“双端部署”与“备案分离”架构：

1.  **Landing Page 独立引流**: `landing_page/index.html` (主域名) 作为纯静态入口，保留原状，仅将卡片链接全部更新为指向新版 SPA 的 Hash 路由格式。
2.  **双环境部署支持**:
    *   更新了 `server/server.js`，确保在**阿里云**上继续提供 API 接口（包括解析短链接和注入 `ICP_NUMBER`）。
    *   重写了 GitHub Actions (`deploy.yml`) 部署脚本，增加了 Node.js `npm run build` 流程，并精准剔除无用文件，提升了 SCP 传输效率。

---

## 📝 遗留问题与提醒
*   本地开发时，Vite 的终端里可能偶尔会报出 `[vite] http proxy error: /api/app-config`，这是由于热更新期间 Vite Server 与 Express Server 断开的正常现象，不影响使用。
*   未来如果需要增加新工具，只需在 `src/views/` 下新建组件，并在 `router/index.js` 和 `HomeView.vue` 的 `tools` 数组中登记即可，无需再手写重复的 HTML 骨架。
