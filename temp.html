📐 详细解答与推导过程

💡 步骤一：共性几何性质探究（切线长与垂足中位线）

设双曲线的标准方程为 $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1\ (a>0, b>0)$，其半焦距为 $c = \sqrt{a^2+b^2}$，左右焦点分别为 $F_1(-c, 0), F_2(c, 0)$。

  • 圆 $D$ 的方程与切线性质：
    以实轴为直径的圆 $D$ 圆心为原点 $O(0,0)$，半径为 $r = a$。过 $F_1$ 作圆 $D$ 的切线，切点记为 $P$。因为 $OP \perp F_1N$，在 Rt$\triangle OPF_1$ 中，斜边 $|OF_1|=c$，直角边 $|OP|=a$，根据勾股定理可得切线长： $$|F_1P| = \sqrt{|OF_1|^2 - |OP|^2} = \sqrt{c^2 - a^2} = b$$
  • 垂足 $Q$ 与中位线定理（极其巧妙的几何突破口）：
    过右焦点 $F_2$ 作直线 $F_1N$ 的垂线，垂足记为 $Q$。因为 $OP \perp F_1N$ 且 $F_2Q \perp F_1N$，所以 $OP \parallel F_2Q$。
    又因为 $O$ 为线段 $F_1F_2$ 的中点，在 $\triangle F_1QF_2$ 中，$OP$ 为中位线！因此可得垂足 $Q$ 的两大核心几何关系： $$|F_2Q| = 2|OP| = 2a, \quad |F_1Q| = 2|F_1P| = 2b$$
  • 在 Rt$\triangle NQF_2$ 中利用三角函数值：
    题设给出 $\cos \angle F_1NF_2 = \cos \angle QNF_2 = \frac{3}{5}$。设 $|NQ| = 3k\ (k>0)$，则斜边 $|NF_2| = 5k$，直角边 $|F_2Q| = \sqrt{(5k)^2 - (3k)^2} = 4k$。
    结合上面证得的 $|F_2Q| = 2a$，可得 $4k = 2a \implies k = \frac{1}{2}a$。由此得到线段长通解： $$|NF_2| = 5k = \frac{5}{2}a, \quad |NQ| = 3k = \frac{3}{2}a$$

🏆 步骤二：情形一 —— 当交点 $N$ 在双曲线右支（高考官方解，对应选项 C）

由于题干叙述为“切线与 $C$ 交于 $M, N$ 两点”，默认习惯下当切线与双曲线右支相交于点 $N$ 时：

  • 利用双曲线右支定义：
    点 $N$ 在右支上，满足 $|NF_1| - |NF_2| = 2a$。将 $|NF_2| = \frac{5}{2}a$ 代入，得： $$|NF_1| = |NF_2| + 2a = \frac{5}{2}a + 2a = \frac{9}{2}a$$
  • 利用直线上各点共线顺序联立方程：
    如上方图示观察可知，此时直线上点的顺序为 $F_1 - P - Q - N$，垂足 $Q$ 位于线段 $F_1N$ 上。因此有： $$|NF_1| = |NQ| + |F_1Q|$$ 将各代数式代入上式： $$\frac{9}{2}a = \frac{3}{2}a + 2b \implies 3a = 2b \implies \frac{b}{a} = \frac{3}{2}$$
  • 计算双曲线离心率 $e$：
    $$e = \frac{c}{a} = \sqrt{1 + \left(\frac{b}{a}\right)^2} = \sqrt{1 + \left(\frac{3}{2}\right)^2} = \sqrt{1 + \frac{9}{4}} = \frac{\sqrt{13}}{2}$$ 所以，官方命题对应的正确答案为 C。

🔍 步骤三：情形二 —— 当交点 $N$ 在双曲线左支（硬核探讨解，对应选项 A）

值得注意的是，题干叙述中切线与圆 $D$ 只有一个切点 $P$，且由于双曲线有两支，切线完全有可能与左支相交于点 $N$：

  • 利用双曲线左支定义：
    点 $N$ 在左支上，离左焦点 $F_1$ 更近，满足 $|NF_2| - |NF_1| = 2a$。将 $|NF_2| = \frac{5}{2}a$ 代入，得： $$|NF_1| = |NF_2| - 2a = \frac{5}{2}a - 2a = \frac{1}{2}a$$
  • 利用直线上各点共线顺序联立方程：
    观察左支情形几何图示可知，此时直线上点的顺序变为 $N - F_1 - P - Q$，即左焦点 $F_1$ 被夹在 $N$ 与垂足 $Q$ 之间！因此有： $$|NQ| = |NF_1| + |F_1Q|$$ 将各代数式代入上式： $$\frac{3}{2}a = \frac{1}{2}a + 2b \implies a = 2b \implies \frac{b}{a} = \frac{1}{2}$$
  • 计算双曲线离心率 $e$：
    $$e = \frac{c}{a} = \sqrt{1 + \left(\frac{b}{a}\right)^2} = \sqrt{1 + \left(\frac{1}{2}\right)^2} = \sqrt{1 + \frac{1}{4}} = \frac{\sqrt{5}}{2}$$ 所以，若交点 $N$ 在左支，离心率计算结果为 $\frac{\sqrt{5}}{2}$，对应答案为 A。
